Methodology and Limitations

What this system predicts

For every (forecast cycle, lead time, grid cell), from Day 1 to Day 10, the system estimates:

  1. the probability of a forecast bust, meaning an unusually large forecast error,
  2. the expected error magnitude for rainfall, temperature, wind and pressure,
  3. a meteorological explanation of why confidence is high or low.

Each training row combines the forecast state, ensemble statistics, forecast volatility, historical analogue statistics, weather regime and location context. These are paired with the verifying observation, the resulting error and a bust label.

Bust definition

The hybrid method labels a bust only when the error exceeds both:

  • the 90th percentile of the training-period error climatology, and
  • an absolute floor per variable.

The sandbox floors are scaled to the toy atmosphere (rain 5 mm/day, temperature 2.5 K, wind 4 m/s, pressure 2 hPa). For real data, configs/default.yaml switches to 35 mm/day, 4 K, 6 m/s and 4 hPa. The percentile makes the label relative to what is unusual for that variable and lead time. The floor stops tiny errors in very predictable conditions from counting as busts.

Confidence score

Confidence = 100 × (1 − bust probability). It is a derived operational indicator, not the probability that the forecast is correct.

Feature engineering (six blocks, 83 features)

BlockContents
nwp Forecast state plus derived dynamics: 850 hPa vorticity and divergence, moisture-flux convergence, MSLP and geopotential gradients, MSLP Laplacian, lapse-rate proxy, precipitable-water anomaly, precipitation peakiness
ens Ensemble mean, standard deviation, IQR, q90, coefficient of variation, exceedance probabilities (10/25/50 mm), spread of wind, temperature and pressure
vol Forecast Volatility Index. The T−24h cycle is compared with the current cycle for the same valid time, covering revisions in each variable, change in spread and a pattern-displacement proxy.
ana Historical analogue statistics (see the analogue engine below)
regime Distance to and depth of detected tropical cyclones, monsoon lows, western disturbances and cyclonic circulations, all detected in the forecast pressure field
ctx Lead time, seasonality (sin/cos day of year), latitude, longitude, terrain height and gradient, land fraction, large-scale indices

Models used

1. Historical analogue engine (non-parametric, no learned weights). The forecast-situation embedding is standardised and reduced by PCA to 8 components. A KD-tree built only on training-period situations retrieves the 25 nearest neighbours, excluding any within ±5 days of the query cycle. It returns mean similarity, the neighbours’ historical bust frequency, and their mean error and spread. This feeds the ana_* features and the analogue search endpoint. No language model is involved.

2. Baseline model ladder. Every model is evaluated identically on the same held-out data, so each gain is attributable.

  • Climatology: predicts the base rate. It is the reference for Brier skill.
  • Ensemble spread alone: a single-signal baseline (ROC-AUC 0.792, PR-AUC 0.380).
  • Forecast volatility alone: a single-signal baseline (ROC-AUC 0.825, PR-AUC 0.351).
  • Logistic regression: an interpretable linear model over all features (PR-AUC 0.522, Brier skill 0.291).
  • Gradient boosting: a sequential tree ensemble (PR-AUC 0.505, Brier skill 0.282).
  • Random forest: a bagged tree ensemble and the best performer (PR-AUC 0.525, Brier skill 0.299, recall 0.285).

3. Isotonic calibration. A monotonic, non-parametric recalibration fitted on the validation split only. It makes predicted probabilities behave like frequencies (calibration error about 0.013).

4. Variable-specific bust classifiers (four). Separate classifiers for precipitation, temperature, wind and pressure, so the system can say why confidence is low. Wind performs best (PR-AUC 0.404) and pressure worst (PR-AUC 0.071).

5. Error-magnitude regressors (four). They predict absolute error for rain (mm/day), 2 m temperature (K), 10 m vector wind (m/s) and MSLP (hPa). They beat lead-time climatology by 25–51% in MAE.

6. Explanation layer (rule-based and model-based).

  • Group attribution: replace a feature block with its training medians, re-run the model and report the drop in bust probability.
  • Diagnostic reasons: each reason is tied to one named feature. It fires only when that feature is in the tail of its training climatology for that lead time, and the sentence quotes the real value and units.

Why no deep learning: the feature-group ablation shows the tabular features are not yet saturated, and there are only about 207k training rows. A ConvLSTM would add novelty but no demonstrated gain in accuracy, calibration or interpretability.

Evaluation design

  • Splits are strictly chronological (train 206,910 rows; held-out test 52,470 rows, 2024-06-01 to 2025-05-31). Samples are never shuffled across time.
  • Calibration is fitted on the validation split only.
  • Reported checks: model ladder, feature-group ablation, permutation importance, spatial cross-validation (east India and the Bay of Bengal withheld), and stratified evaluation by event type.
  • Each retraining writes a model card with the period, feature blocks, metrics, calibration method and git commit.

Limitations

  • Synthetic data. Sandbox mode uses a stochastic toy atmosphere. Results validate the pipeline, not real-world skill, and no result here is a scientific claim about real forecast busts. Real ERA5, TIGGE, IMD or GEFS data has not been tested.
  • Modest recall. The best model has a recall of about 0.28 at its operating point, so most busts are missed. Precision is stronger than recall.
  • Western disturbances. Recall is near zero (0.005) despite a 24% base rate. The system is much stronger for tropical cyclones, monsoon lows and observed heavy rainfall.
  • Pressure busts. PR-AUC is 0.07 with a Brier skill of 0.026, so pressure-specific predictions are weak.
  • Geographic transfer. On regions never seen in training, PR-AUC falls from 0.524 to 0.461 and ROC-AUC from 0.876 to 0.793. The model is partly location-aware.
  • Feature block trade-off. Adding the regime block slightly lowers PR-AUC. It is kept for the explanation layer.
  • Target leakage was found and removed. An earlier version used event-proximity features from the verifying event catalogue, and PR-AUC fell from 0.669 to 0.505 once they were replaced.
  • Explanations are associative. They show which features are unusual, not causal proof of why the forecast failed.
  • Verification sensitivity. The IMD 0830 IST accumulation window and GRIB accumulation conventions can silently corrupt every error metric if mishandled.
  • Confidence bands are UI conventions, not scientifically universal categories.
